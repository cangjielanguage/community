## 社区治理组织架构

仓颉开源社区通过[仓颉语言项目管理委员会](https://gitcode.com/Cangjie/community/blob/main/cangjie_pmc/pmc.md)（ Project Management Committee）管理仓颉语言项目。



## 开发者社区贡献指南

请阅读[如何贡献](https://gitcode.com/Cangjie/community/blob/main/contribute/contribution.md)获得帮助。



## 签署开发者原创声明

您必须首先签署“开发者原创声明”，然后才能参与社区贡献。

点击[这里](https://clasign.cangjie-lang.cn/sign-cla)签署、查看签署状态。
