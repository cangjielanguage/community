# Cangjie Core Team会议运作制度

# 第一条 总则

Cangjie Core Team为仓颉项目群的最高决策机构。Cangjie Core Team定期举行会议，讨论和决策仓颉项目群重大事务。

为了规范Cangjie Core Team会议，根据《仓颉项目群开源治理制度》制定本会议运作制度。

# 第二条 会议发起和召集

根据《仓颉项目群开源治理制度》第8条第5款规定发起和召集。

# 第三条 会议制度

1、 参会人员

（1）全程与会人：Cangjie Core Team委员（含委托）、仓颉项目群执行总监。

（2）全程列席人：仓颉技术指导委员会主席。

（3）议题相关人：会议议题相关人员。说明：仅在该议题时间段参会，议题结束即退出会议。

（4）会务支撑人员：经仓颉项目群执行总监批准的会务支撑人员。

2、 会议纪要

（1） 纪要撰写：由申报议题时指定的纪要人撰写议题纪要。

（2） 纪要汇总：仓颉项目群执行总监批准的会务支撑人员在会议结束2日内向纪要人收集会议纪要。

（3） 纪要审核：由仓颉项目群执行总监审核。

（4） 纪要发送：审核通过后，由仓颉项目群执行总监批准的会务支撑人员将会议纪要邮件发送给与会人。

（5） 纪要发送范围：向Cangjie Core Team会议全程与会人和全程列席人发送全部会议纪要，向议题相关人发送与之相关议题的会议纪要。

3、 会议材料归档

（1）归档内容：

- 会议议题材料归档：仓颉项目群执行总监批准的会务支撑人员从议题汇报人收集材料并归档；
- 会议纪要归档：会议纪要审批通过后由仓颉项目群执行总监批准的会务支撑人员归档；
- 会议记录归档：会议全程录屏或者录像由仓颉项目群执行总监批准的会务支撑人员归档；

说明：会议材料默认对Cangjie Core Team全体委员公开，如因特殊原因不便公开，汇报人应主动提出，经仓颉项目群执行总监确认后，对相关联的材料，如纪要、录屏等进行处理或不予归档，并记录相应情况。

（2） 归档途径：Cangjie Core Team共享空间平台。

（3） 查看权限：面向Cangjie Core Team全体委员开设只读权限。

（4） 归档时长：4年。

# 第四条 生效

Cangjie Core Team会议运作制度自Cangjie Core Team决策批准之日起生效，由Cangjie Core Team管理。

# 第五条 制订、修改及解释

Cangjie Core Team会议运作制度的制订、修改及解释由Cangjie Core Team负责。
