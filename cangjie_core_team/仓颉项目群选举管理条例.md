# 仓颉项目群选举管理条例
# 第一章 总则
## 1.1 第一条 总则
为明确仓颉项目群Cangjie Core Team主席以及 Cangjie Core Team 下设各机构的选举程序以及与选举有关的规则，根据《仓颉项目群开源治理制度》，Cangjie Core Team制定本选举管理条例。

## 1.2 第二条 选举工作组
1、为完成 Cangjie Core Team 选举工作，在Cangjie Core Team下设置选举工作组。

2、选举工作组成员资格：

(1)具有完全民事行为能力，且熟悉选举工作和选举程序；

(2)热衷于从事开源工作，为仓颉项目群服务超过一年；

(3)作出书面承诺并按照选举规则客观、公正地执行选举工作。

3、对选举工作组成员的限制：

(1)不得参选选举管理条例中规定的被选举职位；

(2)不得以任何形式为任何参选人拉票或抵制选票；

(3)在选举过程中遵守保密规定，未经批准不得发布选举过程和结果信息；

(4)不得有其他任何违背社区行为准则或影响选举公正性的行为。

4、选举工作组的构成及任期

(1)选举工作组由5人组成，其中组长1人，组员4人；

(2)选举工作组组长及组员均由Cangjie Core Team提名，并由Cangjie Core Team批准后任命；

(3)选举工作组在仓颉项目群选举工作启动前成立，当届选举工作完成后自动解散。

5、选举工作组职责

(1)根据本选举管理条例组织仓颉项目群选举工作；

(2)对参选人和选举人进行资格审查；

(3)制订选举计划，公布选举流程，执行选举工作；

(4)将选举结果提交对应审核组织评审，审核通过后公布选举结果；

(5)维护选举过程中的选举秩序，对有违公正选举的言论和行为提出警告并予以禁止，情节严重的，可上报Cangjie Core Team，经Cangjie Core Team批准后可取消选举或候选资格；

(6)接受并回答选举人和参选人提出的与选举事宜相关的质询。

# 第二章 Cangjie Core Team主席选举机制和副主席产生机制

## 2.1 第三条 Cangjie Core Team选举职位的设立及人数

1、Cangjie Core Team应选职位为：Cangjie Core Team主席；

2、Cangjie Core Team主席一名。

## 2.2 第四条 Cangjie Core Team主席候选人的产生

1、Cangjie Core Team委员可向选举工作组提交Cangjie Core Team主席参选申请表申请成为Cangjie Core Team主席候选人；Cangjie Core Team主席参选人需所在上级部门批准方可任职者，须在提交Cangjie Core Team主席参选申请表时同时提交参选人上级单位的同意任职函。同一（法人）单位（含关联公司）最多一人参选Cangjie Core Team主席。

2、有下列情形中任一款的个人或机构代表不得参选Cangjie Core Team主席：

(1)因违反仓颉社区规章而被终止资格的上一届Cangjie Core Team委员。

(2)违背仓颉项目群社区行为准则并被证明属实者。

(3)有损害仓颉项目群利益的言行或严重不端行为者。

3、选举工作组根据本条第1、2款规定对Cangjie Core Team主席参选人进行资格审查。Cangjie Core Team主席参选人通过资格审查后成为Cangjie Core Team主席候选人。

## 2.3 第五条 Cangjie Core Team主席产生机制
Cangjie Core Team委员（含Cangjie Core Team主席候选人）对Cangjie Core Team主席候选人进行第一轮投票，每人一票，可以弃权。

1、得票最高的Cangjie Core Team主席候选人签署《任职承诺书》后由华为技术有限公司任命，履行应尽工作职责。

2、如果第一轮投票最高票数相同的，则第二轮投票仅由Cangjie Core Team委员投票。得票最高的Cangjie Core Team主席候选人签署《任职承诺书》后由华为技术有限公司任命，履行应尽工作职责。

3、若第二轮投票最高票数仍相同的，则由华为技术有限公司组织协调裁决。经华为技术有限公司裁决后产生的Cangjie Core Team主席候选人签署《任职承诺书》后由基金会秘书处正式任命，履行应尽工作职责。

## 2.4 第六条 Cangjie Core Team副主席产生机制
Cangjie Core Team主席产生后，Cangjie Core Team其他委员当选Cangjie Core Team副主席。

# 第三章 技术指导委员会选举机制
技术指导委员会由下列人员组成：技术指导委员会主席一名，以及其他需要选举产生的委员若干名。

## 3.1 第七条 技术指导委员会选举职位的设立及人数

1、技术指导委员会应选职位为：技术指导委员会主席、技术指导委员会委员；

2、技术指导委员会主席一名，技术指导委员会委员若干名。

## 3.2 第八条 技术指导委员会委员候选人的产生

1、技术指导委员会委员参选人必须是现任仓颉项目群的Team Leader，并通过以下方式产生：

(1)由技术指导委员会提名；

(2)或自荐，需获得至少八名技术指导委员会现任委员书面推荐。

## 2、有下列情形中任一款的个人或机构代表不得参选技术指导委员会委员：

(1)在前一届技术指导委员会中因违反社区规章而被终止资格的委员。

(2)违背仓颉项目群社区行为准则并被证明属实者。

(3)有损害仓颉项目群利益的言行或严重不端行为者。

3、选举工作组根据本条第1-3款规定对技术指导委员会委员参选人进行资格审查。技术指导委员会委员参选人通过资格审查后成为技术指导委员会委员候选人。

## 3.3 第九条 技术指导委员会委员的产生

1、由现任仓颉项目群的Team Leader担任的技术指导委员会委员：公共技术组的界定由技术指导委员会正式决议后生效；现任仓颉项目群的Team Leader由各自Team的Committer、代码贡献者推举产生。选举工作组根据本选举管理条例第八条第2-3款规定对现任仓颉项目群的Team Leader进行资格审核，现任仓颉项目群的Team Leader通过资格审核后成为技术指导委员会委员。

2、需选举产生的技术指导委员会委员：技术指导委员会委员候选人在技术指导委员会进行述职，技术指导委员会现任委员根据候选人述职情况进行投票，每人一票，可以弃权，按照简单多数原则当选。在技术指导委员会委员选举过程中如果出现因为票数相同无法确定人选的情况，由技术指导委员会主席裁决选举结果。技术指导委员会委员选举过程可邀请行业内有影响力的专家与会见证。

3、技术指导委员会委员需所在上级部门批准方可任职者，须在当选后补充提交其上级单位的同意任职函；如果无法提供则取消其技术指导委员会委员资格且接受缺位。

## 3.4 第十条 技术指导委员会主席选举程序

1、技术指导委员会主席在技术指导委员会委员产生后进行选举。

2、技术指导委员会委员填写参选技术指导委员会主席申请表后成为技术指导委员会主席候选人。

3、技术指导委员会委员（含技术指导委员会主席候选人）对技术指导委员会主席候选人进行投票，每人一票，可以弃权；第一轮投票结束后，按照简单多数原则当选；如果第一轮投票最高票数相同的，则第二轮只针对前述最高票数技术指导委员会主席候选人进行投票，按照简单多数原则当选。若第二轮投票最高票数仍相同的，则由Cangjie Core Team主席裁决。

4、技术指导委员会主席当选后，须经Cangjie Core Team审议后正式任命。

# 第四章 附则

## 4.1 第十一条 制订、修改及解释

本选举管理条例的制订、修改及解释由Cangjie Core Team负责。

## 4.2 第十二条 生效

本选举管理条例经Cangjie Core Team投票通过，并向华为技术有限公司报批通过后生效。
