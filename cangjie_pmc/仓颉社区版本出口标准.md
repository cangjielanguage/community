# 仓颉LTS/STS版本出口标准

| 分类说明 | Nightly版本                      | STS版本                                                      | LTS版本                                        |
| --------------- | ------------------------------ | ------------------------------------------------------------ | --------------------------------------- |
| 能力目标 | 尝鲜版本，支持特性级别尝鲜验证 | 基本功能稳定，支持厂商联调开发和验证                         | 功能稳定，通过专项测试，支持三方厂商商业化集成 |
| 发布周期 | 每日构建，发布件保留1个月      | 6个月，每年12月，或6月发布，不定时补丁版本，下个版本release后归档上个版本 | 2年，提供3年社区支持，每个月补丁版本，维护3年  |
| 获取渠道 | 每日构建流水线                 | 根据版本正式公告                                             | 根据版本正式公告                               |
| 质量说明 | 基本功能验证                     | 稳定版本，存在未完全稳定的尝鲜特性               | 稳定版本，经过兼容性和长期稳定测试             |
