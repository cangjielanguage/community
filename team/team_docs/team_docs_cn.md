# team_docs
## Docs Team工作目标和范围

### 工作目标
 负责仓颉语言文档的社区需求规划和梳理对应领域的共建需求梳理。

### 工作范围
- 文档规划和信息架构设计、文档版本生命周期管理，风格指南等质量保证和标准化规范制定、文档贡献流程建设、文档维护更新、审核文档、响应并处理社区文档问题反馈。
